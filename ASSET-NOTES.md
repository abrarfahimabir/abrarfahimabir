# Profile artwork and data

- Original banner, orbital monogram, pipeline, project illustrations, contact card and button artwork are included with editable Python source.
- GIFs are real looping animations. PNG counterparts provide still alternatives through supported picture/source media queries.
- The wide and compact heroes share the same identity and copy. All artwork uses an opaque dark card to stay legible in GitHub's light and dark themes.
- Project cards are conceptual illustrations, not screenshots or live controls. Feature copy is based on the public SkillStream and Ostad.Blog repositories.
- Tech-chip logo paths come from Simple Icons, CC0-1.0: https://simpleicons.org. Embedded paths are recorded in scripts/icons.json. Django REST uses an original API text mark instead of an invented official logo.
- Open Sans and DejaVu Sans Mono are bundled for reproducible rendering. Their license notices are included in scripts/fonts/.
- Public-code percentages are based on bytes returned by GitHub's languages API. They exclude forks, archived repos, empty repos and profile.config.json's activity.exclude list. They are not proficiency ratings or contribution counts.
- Recent push dates are repository metadata, not commit-by-commit activity attributed to the profile owner.
- GitHub sanitizes README HTML. No external scripts, iframe, custom stylesheet, fake visitor counter, fabricated stat or personal access token is used.
